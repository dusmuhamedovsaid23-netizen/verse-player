# Verse — плеер с синхронизированным текстом песен

Полностью рабочий музыкальный плеер в духе Spotify Lyrics / Apple Music: загружаете
MP3 и текст песни (обычный или LRC с таймкодами) — сайт проигрывает трек и построчно
подсвечивает текст в такт музыке, с плавной прокруткой, кликом-перемоткой по строкам,
ручной синхронизацией, полноэкранным режимом и сохранением библиотеки в браузере.

Технологии: чистые HTML / CSS / JavaScript (ES-модули), без сборки, без фреймворков и
без интернет-зависимостей в рантайме (кроме двух шрифтов Google Fonts).
Хранение — IndexedDB (аудио, обложки, тексты) + localStorage (настройки).

## Как запустить локально

Проект не требует npm install и сборки — но т.к. используются ES-модули (`import`) и
`fetch()` для демо-файлов, открыть `index.html` напрямую двойным щелчком (`file://`)
браузер не даст из-за CORS. Нужен любой локальный сервер статики. Проще всего:

**Вариант 1 — Python (обычно уже установлен):**
```bash
cd lyrics-sync-player
python3 -m http.server 8080
```
Затем откройте http://localhost:8080/index.html

**Вариант 2 — Node.js:**
```bash
cd lyrics-sync-player
npx serve .
```
(или `npx http-server .`) — откройте адрес, который выведет команда.

**Вариант 3 — VS Code:** расширение «Live Server» → «Go Live».

Интернет нужен только для загрузки двух шрифтов (Fraunces, Manrope) с Google Fonts;
если сети нет, сайт всё равно полностью работает — просто со шрифтами по умолчанию.

## Как пользоваться

1. Нажмите на иконку загрузки (⬆) вверху слева или кнопку «Загрузить песню» на
   пустом экране.
2. Выберите аудиофайл, при желании — обложку, впишите название/исполнителя и
   вставьте текст песни.
   - Можно вставить обычный текст (без таймкодов) — тогда после загрузки
     автоматически включится **ручная синхронизация**.
   - Можно вставить LRC-формат с таймкодами вида `[00:12.50] Строка текста` —
     тогда синхронизация подхватится сразу.
   - Кнопка «Загрузить пример» подставляет тестовый трек и текст для проверки.
3. В режиме ручной синхронизации: нажмите Play, слушайте трек и в нужный момент
   нажимайте «Отметить» (или Enter) — это фиксирует текущее время как таймкод
   активной строки и переходит к следующей. Можно вернуться назад, пропустить
   строку или завершить синхронизацию досрочно (не отмеченные строки получат
   интерполированное время). Пересинхронизировать текст позже можно из
   настроек («Пересинхронизировать вручную»).
4. Во время обычного воспроизведения клик по любой строке текста перематывает
   трек к её таймкоду.
5. Иконка справа сверху открывает «Мои песни» (сохранённая библиотека) и
   «Настройки» (размер и шрифт текста, скорость анимации прокрутки текста,
   повторная синхронизация, очистка данных).
6. Кнопка во весь экран убирает обложку и оставляет только текст на весь экран.
7. Стрелку вниз рядом с плеером можно скрыть/показать панель управления, чтобы
   текст занимал весь экран.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Space | Play / Pause |
| ← / → | Перемотка на 10 секунд назад/вперёд |
| Enter (в режиме синхронизации) | Отметить текущую строку |
| ← / → (в режиме синхронизации) | Предыдущая / следующая строка |

## Что уже реализовано и работает «из коробки»

- Реальное воспроизведение загруженного MP3/WAV/OGG файла, play/pause, перемотка
  ползунком, отображение текущего времени и длительности, громкость, повтор трека.
- Парсинг LRC-таймкодов (`[mm:ss.xx]`), автоопределение активной строки по времени
  аудио, плавная прокрутка так, чтобы активная строка оставалась в центре, клик по
  строке — перемотка.
- Полный цикл ручной синхронизации текста без таймкодов, с редактированием позже.
- Динамический фон: размытая затемнённая обложка песни или анимированный
  абстрактный градиент, если обложки нет.
- Тёмная премиальная тема, крупные скругления, аккуратные SVG-иконки, адаптивная
  вёрстка для телефона (текст на весь экран, плеер снизу, без перекрытий),
  планшета и десктопа (обложка + текст рядом).
- Настройки размера и шрифта текста, скорости анимации переходов между строками,
  скрытие/показ плеера, полноэкранный режим.
- Сохранение всех загруженных песен (аудио, обложка, текст, таймкоды) в
  IndexedDB и настроек в localStorage — после перезагрузки страницы последняя
  открытая песня и вся библиотека остаются на месте.
- Корректная адаптация при изменении размера окна (активная строка
  перецентрируется).

## Проверено

Воспроизведение, синхронизация по LRC, перемотка ползунком и кликом по строке,
ручная синхронизация целиком, сохранение и восстановление после перезагрузки
страницы, мобильная раскладка (390×844, без горизонтальной прокрутки), отсутствие
ошибок в консоли — протестировано автоматическим headless-браузером перед сдачей.
